# Shree Ganesh Polymer — Website

Next.js 15 (App Router) · JSX · Tailwind CSS v4 · Framer Motion · lucide-react

## Run
npm install
npm run dev      # http://localhost:3000

## Customise
- Brand colours: app/globals.css (@theme)
- Client names -> logos: components/Clients.jsx (put images in /public/clients)
- Contact form currently opens the visitor's email app; swap onSubmit in
  components/Contact.jsx for an API route or form service if needed.
